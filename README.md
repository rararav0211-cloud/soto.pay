# 桑都ペイ 改善提案デモアプリ

八王子市のデジタル地域通貨「桑都ペイ」の改善提案（チームシノズ「地域通貨を活用した八王子市の地域内経済循環の促進」）を、スマートフォンの画面で見せるためのデモアプリです。

**観光 × 地域通貨**：高尾山に集中している観光客を、回遊クーポンとスタンプラリーで市内のお店へ回遊させる仕組みと、デジタルデバイドへの配慮を、実際に操作できる形にしています。

> ※ 店名は八王子に実在するお店・施設を使っていますが、クーポン・ポイント・予約・公共料金などの内容はすべてデモ用の仮のものです。実際の桑都ペイとは関係ありません。

---

## 動かし方

HTML・CSS・JavaScript だけで作っています。ビルドやインストールは不要です。

1. このリポジトリをダウンロード（`git clone`）する
2. フォルダをローカルサーバーで開く
   - VS Code の拡張機能「Live Server」で `index.html` を開く
   - または、フォルダで `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` を開く
3. スマートフォンの幅で見る（パソコンなら開発者ツールでスマートフォン表示にする）

- ファイルをダブルクリックで開くこともできますが、ローカルサーバーで開くのがおすすめです。**カメラ（QRの読み取り）と現在地（近い順）は、ローカルサーバーか https でないと使えません**
- 地図・QRコードの表示と読み取りには、インターネット上のライブラリ（Leaflet・qrcode-generator・jsQR）を使います
- 更新したのに画面が変わらないときは、`Cmd + Shift + R`（Windows は `Ctrl + Shift + R`）で読み込み直してください

## 画面と機能

| ページ | ファイル | 主な機能 |
|---|---|---|
| ホーム | `index.html` | 残高・保有ポイント、加盟店一覧／クーポン／スタンプラリーへの入口、お店の予約、おトクなクーポン |
| 支払う | `pay.html` | 支払いコード（QR）を見せる／お店のQRを読み取る、クーポンを使う |
| 近くのお店・加盟店一覧 | `shops.html` | エリア・カテゴリでしぼりこみ、現在地から近い順、地図 |
| クーポン | `coupons.html` | クーポン一覧（回遊クーポンは解放されたものだけ）。`coupons.html?kind=tour` は回遊クーポンだけ |
| 予約 | `reserve.html` | 食べる・泊まる・体験する の予約（`?type=food` など） |
| 回遊クーポン・スタンプラリー | `stamp.html` | 今日の回遊クーポン、解放のつながり、スタンプラリー、おすすめルート（`?course=id`） |
| アカウント | `account.html` | 会員情報、予約とキャンセル、公共料金、履歴・特典、ヘルプ |
| 予約履歴 | `reservation-history.html` | 来店日を過ぎた予約・キャンセルした予約 |
| ポイント | `points.html` | 総ポイント、うち宿泊・体験ポイント、獲得履歴 |
| 公共料金の引き落とし | `bills.html` | 水道・電気・ガス・市の税金の引き落とし予定（登録はデモのため先に進めない） |
| よくある質問 | `faq.html` | 分類ごとの質問と答え、検索（`faq.html#points` で分類を開く） |

### 提案（スライド）との対応

| 提案 | アプリでの形 |
|---|---|
| 高尾山の人流を市内へ／スタンプラリー形式とモデルコース（p.28・29） | 高尾山エリアで支払うと八王子駅周辺の回遊クーポンが解放。さらに、支払ったお店の「次のお店」のクーポンが開く。メンバーの周回プラン8つを「おすすめルート」に |
| 時間・エリア限定の回遊クーポン（p.31・41） | 解放した回遊クーポンは、その日の23:59まで |
| 有効期限の導入・◯円以上の購入で期限延長（p.30） | 回遊クーポンを持っている日に1回3,000円以上支払うと、期限が翌日の23:59まで延びる |
| 宿泊・体験限定の特化型ポイント（p.31・42） | 宿泊・体験の予約でもらえる「宿泊・体験ポイント」は、宿泊・体験のお店でだけ使える。チャージでもらえる「普通のポイント」はどこでも使える |
| 公共料金支払い等への対応（p.25） | 公共料金を登録すると、引き落とし日に残高から自動で支払う |
| FAQ・チャットボットの導入（p.20） | よくある質問（検索つき） |
| 残高やポイントを一目で確認（p.24） | ホーム・アカウントの残高とポイント、ポイントの詳細ページ |

## ファイルの構成

```
index.html など   … 各ページ（中身の多くは JavaScript で作る）
style.css         … すべてのページの見た目
js/
  data.js         … データ（クーポン・お店・回遊ルート・公共料金・FAQ・デモの履歴など）と設定値
  core.js         … 土台（保存と読み込み・要素づくり・日付の書き方・アイコン・下から出るパネル・描き直し）
  state.js        … アプリの状態と操作（残高・ポイント・クーポン・回遊クーポン・予約・スタンプ・支払い・公共料金）
  demo.js         … 発表・テスト用（デモの履歴を入れる・sotoPayDemo のコマンド）
  ui-*.js         … 複数のページで使う画面の部品（ui-pay.js＝支払い、ui-coupon.js＝クーポン など）
  page-*.js       … そのページだけで使う処理（page-home.js＝ホーム など）
```

- 各ページの最後で、`data.js → core.js → state.js → demo.js → ui-*.js → page-*.js` の順に読み込みます。**この順番は変えないでください**（下のファイルが上のファイルを使います）
- データは `localStorage` に保存されます（同じブラウザで開き直しても残ります）
- `カフェ.webp`・`サウナ.webp`・`ラーメン.webp` は今は使っていません

### よく変えるところ（`js/data.js`）

| 変えたいもの | 場所 |
|---|---|
| クーポン・加盟店 | `COUPONS` / `COUPON_DETAILS` / `SHOPS` |
| おすすめルート（回遊のつながりもここから作られる） | `TOUR_COURSES` |
| 高尾山で支払うと開く八王子駅周辺のクーポン | `TOUR_FROM_TAKAO` |
| 回遊クーポンの期限が延びる金額 | `TOUR_EXTEND.minAmount` |
| スタンプラリーの特典 | `TOUR_REWARDS` |
| 予約でもらえるポイント／チャージでもらえるポイントの割合 | `RESERVE_POINTS` / `CHARGE_POINT_RATE` |
| 公共料金 | `DEMO_BILLS` |
| よくある質問 | `FAQ_CATEGORIES` / `FAQS` |
| アカウントに出す名前 | `USER_NAME` |
| 最初に入っているデモの履歴 | `DEMO_HISTORY` |

FAQ の答えの金額・割合は、上の設定から作っているので、設定を変えても答えがずれません。

## 発表・デモのときに使うもの

### 画面から

- アカウントのいちばん下「**デモをはじめからにする**」：残高・ポイント・クーポン・予約・回遊クーポン・スタンプ・お知らせを最初の状態に戻す（会員番号は残る）
- ホームの回遊クーポンの案内「**高尾山で支払う**」：高尾山エリアのお店だけを出した支払い画面が開く

### ブラウザのコンソールから（`sotoPayDemo`）

| コマンド | すること |
|---|---|
| `sotoPayDemo.reset()` | すべてリセット（開き直すとデモの履歴がもう一度入る） |
| `sotoPayDemo.expire()` | 今日解放した回遊クーポンを、日付が変わったときと同じように消す |
| `sotoPayDemo.dueToday()` | 登録した公共料金の引き落とし日を今日にする（その場で引き落とされる） |
| `sotoPayDemo.log()` | 今日の回遊クーポン（解放した時刻・使った時刻）を表示 |
| `sotoPayDemo.payments()` | 支払いの記録を表示 |
| `sotoPayDemo.reservations()` | 予約の一覧を表示 |
| `sotoPayDemo.points()` | ポイント（うち宿泊・体験ポイント／普通のポイント）と履歴を表示 |

### デモの流れの例

1. ホームの「高尾山で支払う」→ 高尾山ケーブルカー・リフトで支払う → 回遊クーポンが解放される
2. ホームの「スタンプラリー」→ 解放された回遊クーポンと、解放のつながりを見せる
3. セレオ八王子で3,000円以上支払う → クーポンで割引され、回遊クーポンの期限が翌日まで延びる
4. 京王プラザホテル八王子で支払う → 宿泊・体験ポイントが使える（飲食店では使えない）
5. アカウント →「公共料金の引き落とし」→ 引き落としの説明を見せる
6. アカウント →「よくある質問」→ 検索で「かいゆう」と入れる
